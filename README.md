# A'ISHA 🫀 — инструкция

## Что внутри
- `index.html` — само приложение (обложка любви, конверт, счётчик, аудио, админка)
- `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` — установка как PWA
- `firebase-messaging-sw.js` — получает пуши, даже когда приложение закрыто (Android)
- `functions/index.js` — облачная функция, которая шлёт пуш каждые 30 минут

## 1. Разместить файлы
Загрузи ВСЕ файлы из корня этой папки (кроме `functions/`) в корень своего GitHub Pages репозитория — все файлы должны лежать рядом, `sw.js` и `firebase-messaging-sw.js` обязательно в корне сайта.

## 2. Как работает "без установки — не показывает"
При открытии в браузере видно только экран установки. Полный контент (конверт, приветствие, таймер) откроется только когда сайт запущен как установленное приложение (иконка на рабочем столе). На Android кнопка "Установить" работает сразу. На iPhone нужно вручную: Поделиться → «На экран «Домой»».

## 3. Админ-панель
Зажми экран **двумя пальцами на 5 секунд** — появится ввод пароля.
Пароль: **12345**
Там можно:
- задать дату начала и дату окончания отсчёта
- написать приветственный текст на конверте
- загрузить аудио (уходит в Firebase Storage)
- задать особую фразу дня (иногда будет появляться вместо случайной)

## 4. Фразы любви
В приложении уже "зашито" больше 1000 уникальных комбинаций фраз к Айше — они собираются из подборки обращений, признаний и завершений, поэтому не повторяются часто. Они появляются под таймером каждые ~12 секунд, и именно из них выбираются push-уведомления.

## 5. Push-уведомления каждые 30 минут — ВАЖНО
Чтобы уведомления приходили **даже когда приложение полностью закрыто**, одних файлов сайта недостаточно — нужен реальный push-сервис на стороне сервера (это ограничение самого браузера/Android, а не приложения). Я подготовил для этого готовую облачную функцию (`functions/index.js`), её нужно один раз задеплоить:

1. Установи Firebase CLI (на компьютере с интернетом):
   ```
   npm install -g firebase-tools
   firebase login
   ```
2. В папке проекта:
   ```
   firebase init functions
   ```
   — выбери существующий проект **aisha-c1cec**, язык JavaScript.
3. Замени созданный `functions/index.js` и `functions/package.json` на файлы из этой сборки.
4. В консоли Firebase → Project settings → Cloud Messaging — скопируй **VAPID key** (Web Push certificates) и вставь его в `index.html` вместо `"YOUR_VAPID_KEY_HERE"` (ищи строку `vapidKey:`).
5. Задеплой:
   ```
   firebase deploy --only functions
   ```
   Понадобится план **Blaze** (pay-as-you-go) — при таком объёме отправок (раз в 30 минут) стоимость практически нулевая, но без Blaze планировщик (Cloud Scheduler) не заработает.

После этого функция сама, раз в 30 минут, будет брать все сохранённые токены устройств из Firestore (`fcmTokens`) и отправлять пуш со случайной фразой любви — это придёт даже если телефон Айши заблокирован, а приложение закрыто.

## 6. Правила Firestore/Storage
Не забудь открыть доступ на запись для коллекции `config`, `fcmTokens` и папки `audio/` в Storage (или ограничь через Firebase Auth, если нужно приватнее). Сейчас правила по умолчанию — проверь в консоли Firebase, что `config/settings` доступен на чтение всем и на запись — пока просто открыт (для простоты), при желании потом ужесточим под конкретного админа.
